## Project Overview

Front-end development and maintenance of the official website for United World Colleges (UWC) Bolivia, a non-profit organization dedicated to promoting international education and understanding.

**Role:** Front-End Developer | **Organization:** UWC Bolivia | **Status:** Live and Maintained

---

## Project Goals

1. **Information Hub:** Provide comprehensive information about UWC and the Bolivian National Committee
2. **Student Recruitment:** Facilitate the application process for prospective students
3. **Community Engagement:** Connect alumni, volunteers, and supporters
4. **Bilingual Support:** Serve both Spanish and English-speaking audiences
5. **Mobile Accessibility:** Ensure seamless experience across all devices

---

## Technical Implementation

### Front-End Stack

- HTML5, CSS3, JavaScript
- Bootstrap, jQuery
- Responsive Design, Git

### Key Features Implemented

- **Responsive Design:** Mobile-first approach
- **Bilingual Content Management:** Spanish and English
- **SEO Optimization:** Meta tags and structured data
- **Accessibility:** WCAG compliance considerations
